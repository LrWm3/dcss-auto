# Ogre-pressure experiment

Two 50M seed-0 arms test ordinary-only training versus a 10% mixture of small, randomized one-ogre/one-required-monster scenarios. Ordinary and pressure outcomes are logged separately; scenario labels are never policy inputs.

See [EXPERIMENT.md](EXPERIMENT.md) for the design, checks, queue command and interpretation. Shared optimization background: [PERFORMANCE.md](../../PERFORMANCE.md).
